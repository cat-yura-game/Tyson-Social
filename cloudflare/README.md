# Публикация сайта и AI-консультанта через Cloudflare

В этой папке находится готовый Cloudflare Worker. Он одновременно публикует статический сайт из родительской папки и обслуживает закрытый API `/api/chat`.

## Что уже настроено

- OpenRouter вызывается только на сервере; ключ не попадает в HTML или JavaScript браузера.
- По умолчанию используется бесплатный роутер `openrouter/free`.
- В модель передаётся ограниченная база знаний о боте.
- Сообщение ограничено 700 символами, история — 8 сообщениями.
- Один браузер может отправить не более 10 запросов в минуту.
- Сайт и API публикуются одной командой и на одном домене.

## Что нужно сделать владельцу

1. Создать аккаунт Cloudflare и аккаунт OpenRouter.
2. В OpenRouter открыть раздел API Keys и создать ключ.
3. Открыть терминал в этой папке и установить зависимости:

   ```powershell
   npm install
   ```

4. Войти в Cloudflare:

   ```powershell
   npx wrangler login
   ```

5. Сохранить OpenRouter-ключ как зашифрованный секрет Cloudflare:

   ```powershell
   npx wrangler secret put OPENROUTER_API_KEY
   ```

   После команды вставить ключ и подтвердить. Не записывать настоящий ключ в `wrangler.jsonc`, `script.js` или Git.

6. Опубликовать сайт:

   ```powershell
   npm run deploy
   ```

Cloudflare выведет адрес вида `https://zashugannyy-kot-ai.<ваш-поддомен>.workers.dev`.

## Локальная проверка

Скопировать `.dev.vars.example` в `.dev.vars`, заменить пример настоящим ключом и выполнить:

```powershell
npm run dev
```

Файл `.dev.vars` нельзя публиковать или отправлять другим людям.

## Выбор модели

Сейчас в `wrangler.jsonc` установлена бесплатная модель `openrouter/free`. Она подходит для тестирования, но её доступность и качество могут меняться. Для стабильной работы замените значение `OPENROUTER_MODEL` на идентификатор выбранной платной модели OpenRouter и пополните баланс.

## Что рекомендуется перед большим трафиком

- Подключить Cloudflare Turnstile, чтобы сложнее было обходить лимит созданием новых идентификаторов браузера.
- Установить месячный лимит расходов для ключа OpenRouter.
- Добавить политику конфиденциальности и указать, что вопросы отправляются внешнему AI-провайдеру.
